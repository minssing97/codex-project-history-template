# 이미 개발 중인 프로젝트에 템플릿 처음 적용하기

먼저 템플릿의 `AGENTS.md` 규칙을 기존 `AGENTS.md`와 병합하고 `CODEX_HISTORY.md`를 복사한 뒤, 아래 프롬프트를 사용하세요.

---

이 프로젝트에 Codex 개발 이력 관리를 적용해 줘.

1. `AGENTS.md`와 `CODEX_HISTORY.md`를 읽고 규칙을 확인해.
2. 현재 Codex 대화에서 **실제로 확인 가능한** 기존 사용자 프롬프트와 주요 결과를 시간순으로 정리해 `CODEX_HISTORY.md`에 기록해.
3. 이전 대화에 접근할 수 없다면 임의로 복원하지 말고, 실제 코드와 Git 기록에서 확인 가능한 결과만 '코드 기반 확인'이라고 구분해.
4. 각 기록에 주요 수정 파일, 테스트 여부, 미완료 작업을 포함해.
5. 인증정보, 토큰, 비밀번호는 기록하지 마.
6. 개발 소스코드와 기존 지침은 임의로 수정하지 마.
7. 작성한 이력을 보여주고 검토가 필요한 불확실한 부분을 알려줘.
