# Codex 작업 종료 전 이력 점검

다음 프롬프트를 Codex에 복사해 사용하세요.

---

이번 대화에서 수행한 실제 개발 작업을 검토하고 `CODEX_HISTORY.md`를 최신 상태로 정리해 줘.

1. 주요 사용자 프롬프트 원문, 핵심 변경 사항, 수정 파일, 실행한 테스트 결과, 남은 문제를 기록해.
2. 이미 기록된 작업은 중복해서 추가하지 마.
3. 실행하지 않은 테스트는 '미실행'으로 표기하고 성공했다고 주장하지 마.
4. API 키, 인증정보, 민감한 개인정보가 기록되지 않도록 점검해.
5. `git status`를 확인하고 GitHub에 반영할 변경 파일 목록을 알려줘.
6. **커밋과 푸시는 내가 요청하기 전에는 실행하지 마.**
