# 새 PC 또는 새로운 Codex 대화에서 작업 시작

다음 프롬프트를 Codex에 복사해 사용하세요.

---

현재 프로젝트의 `AGENTS.md`, `README.md`, `CODEX_HISTORY.md`를 읽고 개발 맥락을 복원해 줘.

1. 가장 최근 작업 3~5개의 핵심 내용과 주요 기술적 결정을 요약해.
2. Git 변경 상태와 실제 파일을 확인하고, 개발 이력과 현재 구현이 일치하는지 검토해.
3. 현재 구현된 기능, 미해결 문제, 다음 작업 우선순위를 정리해.
4. 확인되지 않은 내용은 추정이라고 표시해.
5. **아직 코드를 변경하지 말고**, 내가 지시하면 다음 작업을 시작해.
